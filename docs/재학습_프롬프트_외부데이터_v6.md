## 신규 데이터 (R1 — 전부 한국어, 번역 불필요)
- DKTC (tunib-ai/DKTC, CC-BY-NC-SA): 협박·갈취·직장내/기타 괴롭힘 → 전량 '주의'. 대화를 3턴 window로.
- K-MHaS (HF jeanlee/kmhas_korean_hate_speech): 멀티라벨 혐오 → label==[8]만 정상, 그 외 주의. 15k 층화표본.
- APEACH (HF jason9693/APEACH): 혐오 이진(0 정상/1 주의).
모두 scripts/adapt_external_datasets.py 가 data/synthetic/{dktc,kmhas,apeach}.jsonl 로 생성하며
홀드아웃(aihub/beep)+소비 blind(v1..v8)와 MinHash(0.8)+exact dedup 을 빌드 시점에 수행한다.

## 목표
- KcELECTRA-base-v2022, num_labels=2, seed=42, 규칙보조 OFF(운영 SAFE_RULE_ASSIST=0 일치).
- config: configs/module1_binary_hardcases_v6.yaml (extra_caution=pan12 predator, extra_train=하드케이스v5+dktc+kmhas+apeach).

## 실행 흐름 — 두 방법 중 하나
### (권장) 노트북
- notebooks/12_iterative_hardcase_retrain_v6.ipynb 를 A100 런타임에서 셀 순서대로 실행.
- 셀3 전에 tests/fixtures/safe_blind_v8.jsonl 이 있어야 함(없으면 assert 중단).

### (동등) 커맨드
0. fresh blind v8 작성: tests/fixtures/safe_blind_v8.jsonl, 40행
   스키마 = v5~v7과 동일 {text, label(0/1), slice, receiver_is_minor}.
   슬라이스 균형(정상 20/위험 20), 위험은 이번 타깃(협박·갈취·괴롭힘) 포함.
   ※ v1~v7은 모두 소비됨 → dev 회귀셋. v8만 fresh.
1. python scripts/adapt_external_datasets.py            # 인터넷 필요(DKTC/HF) + dedup
2. python scripts/download_seed_datasets.py
   python scripts/build_processed_dataset.py
   python scripts/build_final_dataset.py --synth-repeat 1 --include-aihub-train
   python scripts/build_safe_hardcase_dataset.py --include-v5 \
     --output data/synthetic/safe_hardcases_v5/train.jsonl \
     --forbidden tests/fixtures/safe_blind_v6.jsonl \
     --forbidden tests/fixtures/safe_blind_v7.jsonl \
     --forbidden tests/fixtures/safe_blind_v8.jsonl
3. repeat 1→3 학습(게이트 통과 시 중단):
   python scripts/train_module1.py --config configs/module1_binary_hardcases_v6.yaml
   (노트북 셀5는 extra_train_repeat 를 1→2→3 으로 올리며 module1_binary_hardcases_v6_r{n} 저장)
4. dev 게이트(성인 τ 0.40~0.85 스윕, 미성년=성인−0.16, 하한 0.35):
   실 recall≥0.80·specificity≥0.80, dev recall≥0.85·specificity≥0.90,
   fraud·coercive·grooming·digital_extortion recall≥0.80. 규칙보조 OFF.
5. 후보 고정 후 blind v8 최초 1회 평가(SHA256 전후 검증):
   python scripts/evaluate_safe_blind.py --model <SELECTED_ckpt> \
     --data tests/fixtures/safe_blind_v8.jsonl --adult-threshold <a> --minor-threshold <m> \
     --no-rule-assist --output artifacts/safe_blind_v8_results.json

## ⚠ 분포 리스크 (이번 라운드 특유 — 반드시 감시)
- DKTC가 전량 주의(15k)라 신규 주입이 ~67% 주의로 치우침 → 합산 주의비율 59%→63% 상승.

- 게이트에서 specificity가 떨어지면: DKTC 표본 축소(adapt 스크립트 window/per-conv 하향) 또는
  K-MHaS 정상 비중 확대. 각 시도 결과 기록.
