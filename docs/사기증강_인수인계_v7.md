## 현재 상태 (2026-07-22, 커밋 de5cfa4까지 push)

- **목표**: SAFE 이진 모델(정상/주의)의 **금전 사기 커버리지 공백**을 메운다. 사기는 실
  학습 데이터가 없어 규칙 레이어(RULE_ASSIST)로만 임시 보완했고 그마저 꺼둠(ineffective).
- **결정**: A2(데이터+재학습) + B2(LLM 오프라인 라벨 검수). 데이터는 (b) — Gemini 합성 +
  LLM 검수를 코어로 먼저 가동, PsyScam/보이스피싱 벤치마크는 확보되는 대로 씨앗 추가.
- **구현 완료·오프라인 검증**(scam 테스트 7개 통과, ruff 클린):
  - `src/data/llm_client.py` — 주입 가능한 Gemini 클라이언트(429 백오프, 안전필터 해제).
  - `src/data/scam_synthesis.py` — 사기 6유형(주의=1)·경계 반례 3유형(정상=0) 프롬프트,
    `synthesize_scam`/`verify_labels`/`filter_forbidden`. LLM 호출은 주입식+per-call 예외 방어.
  - `scripts/build_scam_dataset.py` — 합성→검수→blind 누수제거→`data/synthetic/scam/train.jsonl`.
  - `configs/module1_binary_hardcases_v7.yaml` — v6 ⊇ + 사기 소스.
  - `tests/fixtures/safe_blind_v9.jsonl` — 손으로 쓴 fresh blind 40행 20/20(사기 슬라이스
    + 정상 금전 경계 반례 benign_money 8행). LLM 합성과 독립.
  - `notebooks/13_scam_augmentation_v7_colab.ipynb` — clone→사기 생성→데이터빌드→v7 재학습
    →blind v9 평가. v6 노트북(12) 패턴 ⊇.

## ⚠ 현재 블로커 (여기서 막힘)

노트북 셀 3(`build_scam_dataset.py`)에서 **Gemini 호출이 실패**해 subprocess exit 1.
자식 stderr가 캡처 안 돼 원인 미확인. de5cfa4에서 per-call 예외를 stderr로 찍도록 강화함
(`[scam] synth:<유형> LLM 호출 실패: <타입>: <메시지>`). 다음 세션은:
1. 셀 1 재실행(git pull) → 셀 3 재실행 → stderr의 실패 메시지 확보.
2. 유력 원인: 모델명 404(`gemini-flash-latest`가 키/리전 미지원 → `--synth-model gemini-2.0-flash`
   등으로 교체), 키/권한 403, 안전차단(KeyError blocked). 기존 `translate_pan12.py`도 같은
   모델명 기본값을 씀 — PAN12 번역 성공 이력이 있으면 모델명은 정상 힌트.
