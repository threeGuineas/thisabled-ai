## 1. 파이프라인 (5단계)

### ① 추출 (대화 window 방식)
- ground truth의 predator ID가 참여한 대화에서 predator 발화를 순서대로 4턴씩 묶은 window로 추출
- 필터: window 합산 최소 단어 수·URL 제거, 대화당 최대 window 수 제한(편중 방지)
- `--predator-only` 사용 (③ 검수 결과 확정) — PAN12 normal은 '정상'으로 쓰지 않는다.
- training 코퍼스 사용. 파일럿 실제 번역 확보: **predator 190 window** (250 목표 중, 무료 티어
  일일 쿼터 소진으로 190 완료 — 재개 로직으로 이후 보충).

### ② 번역·현지화 (Gemini 배치)
- 지시: 직역이 아니라 한국 메신저 대화체로 현지화 — 반말·축약·초성체 일부,
  이름·지역·학교 등 한국식 익명 치환, 문화 맥락(달러→만원, AIM→카톡 등) 변환
- 시스템 프롬프트에 "아동 보호 연구용 유해 대화 번역" 맥락 명시
- 모델: `gemini-flash-latest`, REST 직접 호출, 안전필터 BLOCK_NONE(연구용), 429 백오프 + 개별 폴백
- **파일럿 품질 검수 통과**: 성적 유인·비밀 유도·신뢰형성 등 위험 신호가 순화 없이 보존됨,
  현지화·대화체 자연스러움 양호, 한국어 미포함 0건.
- 산출 스키마: `{text, source:"pan12", split_role, conv_id, win_idx}`

### ③ 품질 검증 — ⚠ 핵심 발견 (2026-07-08)
- **PAN12 normal(IRC/Omegle)은 '정상' 라벨로 부적합.** negative class = "그루밍범이 아닌 사람"
  일 뿐이며, 무작위 낯선 사람 채팅이라 노골적 성적 표현("...피스팅..."), 위험 발언("시체 발견")이
  다수. 이를 정상으로 학습시키면 모델이 "성적 채팅 = 정상"을 배워 SAFE를 오히려 오염.
  → **결정: predator window만 '주의' 증강으로 사용. '정상'은 기존 한국어 시드 clean에서 확보.**
- predator window의 신호 품질은 양호(위 ②). 단 predator의 무신호 턴은 window로 묶어 완화됨.
- 자동 필터: 언어감지(비한국어 제거), 길이, 중복.
- 번역투 편향 가드(아래) 유지.

### ④ 병합·누수 가드
- 라벨: PAN12 predator window → `주의`. `정상`은 시드 clean(Unsmile clean, KOLD OFF=False)에서.
- MinHash 근사 중복 제거 (기존 dedup 모듈) — 합성·시드·AI-Hub와 교차 중복 제거
- 평가 홀드아웃(AI-Hub 실데이터, beep_real_holdout)과 완전 분리 — 번역분은 **train 전용**
- 혼합비 초기값: 전체 train의 5~10% 내 (효과·부작용 보고 조정, 운영 설정으로 기록)

### ⑤ 학습·평가 (이진 v2 기준)
- 라벨: PAN12 predator(검수 통과) → `주의` / `정상`은 시드 clean
- ablation 3종 비교: (a) 시드+합성 (b) +AI-Hub (c) +AI-Hub+PAN12 predator
- 판정 지표: AI-Hub 실데이터 홀드아웃 주의 Recall / 정상 Precision(과블러) / 그루밍 하위셋 Recall
- **번역투 편향 모니터링**(정상은 시드=한국어 원어, 주의는 번역체 → 문체 지름길 위험):
  번역 predator vs 한국어 원어 정상만으로 미니 대조셋을 만들어, 모델이 문체가 아닌 내용으로
  구분하는지 점검. 편향 신호가 크면 정상 측에도 소량 번역분 투입 검토(후속).

## 2. 리스크와 한계 (보고서에 기술)

| 리스크 | 대응 |
|---|---|
| **PAN12 normal ≠ 안전** (성적·거친 IRC/Omegle) | predator-only 사용, 정상은 시드 clean에서 확보 (③ 발견) |
| 턴 단위 라벨 노이즈 (predator의 무해 턴) | window 묶음으로 완화 + 검수 |
| 번역투 지름길 학습 (정상=원어, 주의=번역체) | 문체 대조 미니셋 모니터링, 필요 시 정상 측 소량 번역 |
| 시대·플랫폼 갭 (2000년대 미국 채팅) | 현지화 지시로 완화, 한계로 명시 |
| 원데이터 윤리 (아동 대상 성범죄 대화) | git 밖 보관, 재배포 금지, 보고서엔 통계만 |

## 3. 일정 배치

포함하는 것을 목표로 한다: 7/8 추출·번역 → 7/9 검수·병합·재학습 → 7/10 통합 게이트에서
