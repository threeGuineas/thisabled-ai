# 그루밍 번역 증강 실행 계획 (PAN12 → 한국어)

작성 2026-07-08 · 상위 문서: [safe_라벨_및_판정_기준.md](safe_라벨_및_판정_기준.md) §5
목표: 실제 그루밍 화법을 학습 데이터에 투입해 "합성 템플릿만 잡는 모델" 문제(실데이터 recall 0.005)를 해소

| 항목 | 내용 |

## 1. 파이프라인 (5단계)

### ① 추출
- ground truth의 predator ID가 참여한 대화에서 **predator 발화 턴**만 세그먼트로 추출
- 필터: 3단어 미만·URL·이모티콘만인 턴 제거, 대화당 최대 N턴 샘플링(편중 방지)
- 정상 풀: 같은 포맷으로 IRC/Omegle 정상 대화 턴 추출 (**주의 분량과 1:1**)
- 목표 규모: 주의 3,000~5,000턴 + 정상 동수 (1차분 — 효과 확인 후 증분)

### ② 번역·현지화 (GPT-4o-mini 배치)
- 지시: 직역이 아니라 **한국 메신저 대화체로 현지화** — 반말, 축약, 초성체 일부,
  이름·지역·학교 등은 한국식 익명 치환, 문화 맥락(달러→만원 등) 변환
- 시스템 프롬프트에 "아동 보호 연구용 유해 대화 번역" 맥락 명시 (거부 응답 대비 재시도 로직)
- 예상 비용: 1만 턴 × 평균 30토큰 수준 — GPT-4o-mini 기준 수 달러 내
- 산출 스키마: `{text_ko, source:"pan12", split_role:"predator|normal", conv_id, turn_idx}`

### ③ 품질 검증
- 무작위 200건 수동 검수: 번역 자연스러움 / 그루밍 신호 보존 / 라벨 타당성 (predator 턴이어도
  "ㅇㅋ" 같은 무신호 턴은 **정상으로 재라벨 또는 제외** — 턴 단위 라벨 노이즈가 최대 리스크)
- 자동 필터: 언어감지(비한국어 잔존 제거), 길이, 중복
- **번역투 편향 가드**: 정상·주의 양쪽이 같은 번역 파이프라인을 거치므로 "번역체=주의" 지름길 차단.
  검증: 번역 정상 vs 번역 주의만으로 미니 평가셋을 만들어 모델이 문체가 아닌 내용으로 구분하는지 확인

### ④ 병합·누수 가드
- MinHash 근사 중복 제거 (기존 dedup 모듈 재사용) — 합성·시드·AI-Hub와 교차 중복 제거
- 평가 홀드아웃(AI-Hub 실데이터, beep_real_holdout)과 완전 분리 — 번역분은 **train 전용**
- 혼합비 초기값: 전체 train의 5~10% 내 (효과·부작용 보고 조정, 운영 설정으로 기록)

### ⑤ 학습·평가 (이진 v2 기준)
- 라벨: predator 턴(검수 통과) → `주의`, 정상 턴 → `정상`
- ablation 3종 비교: (a) 시드+합성 (b) +AI-Hub (c) +AI-Hub+PAN12 번역
- 판정 지표: AI-Hub 실데이터 홀드아웃 주의 Recall / 정상 Precision(과블러) / 그루밍 하위셋 Recall

## 2. 리스크와 한계 (보고서에 기술)

| 리스크 | 대응 |
|---|---|
| 턴 단위 라벨 노이즈 (predator의 무해 턴) | ③ 수동 검수 + 무신호 턴 제외 규칙 |
| 번역투 지름길 학습 | 정상도 동일 파이프라인 번역 + 문체 대조 검증 |
| 시대·플랫폼 갭 (2000년대 미국 채팅) | 현지화 지시로 완화, 한계로 명시 |
| 원데이터 윤리 | git 밖 보관, 재배포 금지, 보고서엔 통계만 |

## 3. 일정 배치

**중간평가(7/14) 전 트랙으로 확정 (2026-07-08 재배치).** 이진 전환 재학습에 PAN12 번역분까지
포함하는 것을 목표로 한다: 7/8 추출·번역 → 7/9 검수·병합·재학습 → 7/10 통합 게이트에서
ablation (a) 시드+합성 (b) +AI-Hub (c) +AI-Hub+PAN12 비교 후 서빙 반영 여부 결정.
검수(③)가 지연되면 (b)까지만 서빙에 반영하고 PAN12는 보고서에 진행 중 트랙으로 기술 (폴백).
