## 0. v2 전환 결정과 근거

**결정: 학습 라벨을 `정상(0) / 주의(1)` 이진으로 재정식화한다.**

| 근거 | 설명 |
|---|---|
| 서비스 정합 | 명세 SAFE-03의 화면 상태가 정상/주의 2개. 4-class는 어차피 서빙에서 이진으로 접혔음 (P(1+2+3)≥τ) |
| 불균형 완화 | 긴급(3) 극소수 클래스 문제가 사라짐 — 4-class의 핵심 난점(시드 긴급 0건)이 구조적으로 해소 |
| 증강 용이 | 외국 그루밍 데이터(PAN12 등) 번역분을 세분 라벨 없이 `주의`로 일괄 라벨링 가능 — 라벨 노이즈 최소화 |
| 판정 단순화 | verdict = P(주의) ≥ τ 로 직결. τ 캘리브레이션이 한 확률 축에서 이뤄짐 |

**보존**: 4-class 연구(매핑 정책·실험·실측치)는 모델링 단계 성과로 보고서에 유지.
서사는 "연구: 4단계 위험도 → 운영: 서비스 요구(2단계 표시)에 맞춘 이진 재정식화"로 기술.
**포기하는 것**: 위험 유형·수위의 세분 정보 — SAFE-04 내부 위험 점수의 수위별 가중은
후속(4-class 헤드 병행 또는 멀티태스크)으로 이동.

## 1. 이진 라벨 정의

| 코드 | 라벨 | 정의 |
|---|---|---|
| 0 | 정상 | 위험 신호 없음 — 일상 대화, 일반 의견, 거친 표현 없는 비판 |
| 1 | 주의 | **수신자 보호가 필요한 모든 메시지** = 구 1·2·3의 합집합 |

`주의`에 포함되는 유형 (구 4-class와의 대응):

| 유형 | 구 라벨 | 예 |
|---|---|---|
| 욕설·무례·개인 공격 | 1 | 비꼼, 짜증 섞인 욕설 |
| 보호집단 혐오·차별 | 2 | 집단 겨냥 혐오 표현 |
| 그루밍·성적 유인 | 3a·3b | "우리 둘만의 비밀", 사진 요구 — **욕설 없이 다정한 어조가 특징** |
| 금전 요구·사기 | (규칙 레이어) | 계좌·송금·상품권 요구 |
| 구체적 협박 | 3c | 대상·수단이 구체적인 위협 |
| 자해/자살 신호 | 3d | 자해 암시·계획 |

경계 규칙: "만나자" 단독은 정상 — 고립·비밀 유도 등 결합 신호가 있어야 주의.
boundary 반례 합성 세트(긴급 오분류 방지용)는 이진에서도 `정상` 라벨로 그대로 활용.

## 2. 시드 → 이진 매핑 (구 매핑의 붕괴 규칙)

기존 4-class 매핑을 거친 뒤 `{1,2,3} → 주의`로 붕괴하면 동일 결과. 직접 규칙:

| 데이터셋 | 정상(0) | 주의(1) |
|---|---|---|
| UnSmile | clean=1 | 그룹 혐오 ≥1 또는 악플/욕설=1 |
| KOLD | OFF=False | OFF=True (표적 무관) |
| AI-Hub 558 | is_immoral=False | is_immoral=True |
| GPT-4o 합성 (3a~3d) | boundary 중 정상 판정분 | 전량 주의 |
| **PAN12 번역분 (신규)** | 정상 대화 세그먼트 번역분 | predator 대화 세그먼트 번역분 |

예상 효과: 시드 통합 기준 정상 ≈ 42% / 주의 ≈ 58% — **불균형이 사실상 사라짐**
(4-class의 긴급 0.0x% 문제 소멸). Class weight·Focal·oversample 없이 기본 CE로 시작 가능.

## 3. 서빙 판정 (v2 단순화)

```
verdict = flagged  if  P(주의) ≥ τ  OR  규칙 보조 레이어 히트
          safe     otherwise
```

- τ: 성인 0.50 / 미성년 수신자 0.35 (`SAFE_FLAG_THRESHOLD[_MINOR]`, §4.5 민감 판정 유지)
- 규칙 보조 레이어(금전 사기 패턴) OR 결합 유지 — 번역·합성으로 커버리지가 확보되면 축소 검토
- **서빙 코드 변경점**: `num_labels=2`, `risk_prob = P(주의)` 한 줄 — `/analyze` 계약·응답 형식은 불변

## 4. 프론트 표시 (변경 없음 — 명세 SAFE-03)

| verdict | 화면 | 처리 |
|---|---|---|
| safe | 정상 | 그대로 전달 |
| flagged | 주의 | 블러 + `내용 보기`/`차단`, 열람 결정권은 수신자 |

FE 문구는 "주의"로 통일 ("경고" 사용 금지 — 구 4-class 용어와 혼동 방지). 판정은 수신자에게만
표시. flagged 3회/3일 누적 → 관계 단위 전송 제한(SAFE-05).

## 5. 그루밍 데이터 확보: 외국 데이터 번역 증강 (신규 트랙)

한국어 그루밍 특화 공개 데이터셋은 부재 확인(2026-07-08 조사). 영어 실데이터를 번역해
`주의` 라벨로 투입한다. 상세 실행 계획: [grooming_번역_증강_계획.md](grooming_번역_증강_계획.md)

| 소스 | 내용 | 용도 |
|---|---|---|
| PAN12 (Zenodo 공개) | Perverted Justice 실제 그루밍 채팅 + IRC/Omegle 정상 대화 | predator 세그먼트 번역 → 주의 / 정상 세그먼트 일부 번역 → 정상 |
| PANC / ChatCoder2 | PAN12 재구성 (조기 탐지용 세그먼트) | 시퀀스 탐지는 범위 밖 — 세그먼트 추출 참고 |

핵심 주의: ① 번역투 편향 — 모델이 "번역체 = 주의"를 학습하지 않도록 **정상 대화도 같은
파이프라인으로 번역해 양쪽에 투입** ② 평가 홀드아웃(AI-Hub 실데이터)과 번역분 완전 분리
③ 아동 대상 범죄 원데이터 — 라이선스·윤리 검토, 재배포 금지, 저장소에 원문 커밋 금지.

## 6. 평가 기준 (v2)

| 지표 | 목표 | 비고 |
|---|---|---|
| 주의 Recall (AI-Hub 실데이터 홀드아웃) | ≥ 0.80 | 주 지표 — 미탐 최소화 |
| 그루밍 하위셋 Recall (홀드아웃 내 3a·3b 상당) | 별도 리포트 | 이번 전환의 검증 포인트 |
| 정상 Precision / FP율 | 과블러 검증 | 명세 19.3 "정상 문장을 과도하게 가리는지" |
| τ 캘리브레이션 | PR 곡선으로 재보정 | 성인/미성년 각각 |

## 부록 — 구 4-class 체계 (연구 단계 이력, 보고서 인용용)

0 정상 / 1 주의(무례) / 2 경고(집단 혐오) / 3 긴급(행위 위험: 3a 그루밍, 3b 성적 유인,
3c 협박, 3d 자해 신호). 0~2 강도 축 + 3 행위 축의 비대칭 설계. 시드 긴급 0건 → 합성 보강
→ 합성 홀드아웃 recall 1.0(순환) vs 실데이터 0.005 — 이 갭이 v2 전환의 직접 계기.
