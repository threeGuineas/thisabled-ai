# ThisAbled 중간평가 시연 영상 시나리오 (초안 v1)

- 목표 길이: **3분 30초 ~ 4분**
- 촬영일: 7/12 (일) / 리허설: 7/11 (토)
- 형식: 화면 녹화 + 자막 중심 (나레이션은 선택 — 자막만으로 이해 가능하게, 청각 접근성 원칙과 일치)
- 원칙: 실제 동작만 보여준다. 미구현 기능은 등장시키지 않는다.

## 데모 계정·시드 데이터 (촬영 전 준비, BE)

| 계정 | 닉네임 | 모드 | 역할 |
| --- | --- | --- | --- |
| A | 지수 | 시각장애인 모드 | 주인공 (수신자 관점) |
| B | 민준 | 발달장애인 모드 | 친구 상대역 |
| C | 낯선사람 | 아무 모드 | 위험 발신자 (비친구) |

- A·B는 관심사 태그 2개 이상 겹치게, 연령대 동일하게 설정 (MATCH 사유 출력용)
- 피드에 게시물 4~5개 미리 시드 (촬영 화면이 비어 보이지 않게)
- 사진 게시물용 이미지 1장 준비 (VISION 설명이 잘 나오는 명확한 사진 — 예: 공원에서 강아지)
- 브라우저 프로필 2개(A/B·C)로 나란히 또는 교차 촬영

## 장면 구성

### S0. 인트로 — 10초
- 로고/시작 화면 위에 자막:
  > "장애 유형별 맞춤 UI에서, AI의 보호를 받으며 소통하는 소셜 커뮤니티 — ThisAbled"

### S1. 소셜 로그인·가입·모드 선택 — 30초
1. `카카오로 시작하기` → 로그인 → 추가 정보(닉네임·생년월일·약관)
2. **UI 모드 선택 화면**에서 시각장애인 모드 선택 → 홈 피드 진입
- 자막: "회원가입은 소셜 로그인으로 간단하게. 자신에게 맞는 UI 모드를 선택합니다."
- 강조: 모드 선택이 이 서비스의 정체성 — 화면 전환을 천천히

### S2. 피드·게시물 + AI 사진 설명 (VISION) — 40초
1. A가 사진 게시물 작성 → `게시`
2. 게시물에 **AI 사진 설명**이 자동 부착된 화면
3. 시각 모드: 스크린리더(VoiceOver)가 "AI가 생성한 사진 설명입니다. …"를 읽는 소리를 잠깐 들려줌 (이 구간만 소리 사용 + 동일 내용 자막)
- 자막: "시각장애 사용자를 위해 모든 사진에 AI 설명이 자동 생성됩니다."

### S3. 맞춤 친구 추천 (MATCH) — 30초
1. A의 친구 추천 화면 → 민준이 상위 노출, 사유 표시: **"관심사가 비슷해요 · 비슷한 연령대예요"**
2. 친구 요청 → (B 화면) 수락 → 친구 성립
- 자막: "자체 학습한 SBERT+LightGBM 모델이 잘 맞을 친구를 추천합니다. 장애 유형은 절대 노출하지 않습니다."

### S4. AI 안심 채팅 (SAFE) — 핵심, 60초
1. A↔B 정상 대화 2~3마디 (즉시 전달되는 모습)
2. (C→A는 S5에서, 여기선 B 계정을 잠시 위험 발신자로 사용하거나 친구 관계인 C 사용)
   상대가 위험 메시지 전송: **"계좌번호 알려주면 돈 보내줄게. 급한 거니까 빨리"**
3. A 화면: 메시지가 **블러 처리** + "이 메시지는 위험할 수 있어요" + `내용 보기`/`차단` 버튼
4. `내용 보기` 실행 → 원문 표시
5. (선택 — FE 구현 시) 위험 메시지 3회 누적 → 발신자 전송 차단, A에게 "위험 가능성이 있는 메시지가 반복되어 전송을 제한했어요" 안내 (SAFE-05)
- 자막: "모든 메시지는 자체 파인튜닝 안전 모델이 분석 후 전달됩니다. 열람 결정권은 항상 수신자에게 있습니다."
- ⚠️ 시연 문장은 위 사기 문장(규칙 레이어 확인됨) 또는 협박 문장 사용 — 촬영 전 `/analyze`로 flagged 재확인

### S5. 비친구 메시지 요청함 — 20초
1. C(비친구)가 A에게 메시지 요청 → A의 **요청함**에 분리 표시
2. 위험 판정 요청이면 블러 상태로 표시되는 화면
- 자막: "모르는 사람의 메시지는 분석을 마친 뒤에만 요청함에 나타납니다."

### S6. 기술 컷 — 20초
- 화면 분할: 채팅 → 백엔드 로그 → 모델 서버 응답(JSON: verdict·probs·latency_ms)
- 자막: "KcELECTRA 파인튜닝 + 규칙 하이브리드, 평균 응답 48ms. 텍스트 위험 판정은 외부 전송 없이 자체 모델로 처리합니다."
- (대안: 아키텍처 다이어그램 1장 + 동일 자막)

### S7. 아웃트로 — 10초
- 자막: "다음 단계: 청각·발달 모드 고도화, 자동 자막·소통 코치, 신고·제재 체계. ThisAbled"

## 백업 플랜
- **시각 모드 UI 미완 시**: S1 모드 선택은 그대로, S2의 스크린리더 컷만 제외하고 "사진 설명 자동 생성"까지만 시연. 시각 모드 분량은 최종 발표(10월)로 이월한다고 자막 한 줄.
- **실모델 교체 미반영 시**: mock으로 촬영해도 화면 흐름은 동일 (S6 기술 컷만 실모델 응답으로 별도 녹화 가능 — 로컬 서버로).
