## 1. 학습의 목적 (분석)

**서비스 목적**: ThisAbled는 장애인 대상 소셜 서비스이며, SAFE 모듈은 사용자 간 **1:1 대화에서 수신자를 보호**한다. 명세 SAFE-03의 화면 상태는 `정상`/`주의` 2개이고, 서빙은 `verdict = flagged if P(주의)≥τ`로 판정해 `주의` 메시지를 블러 처리한다(열람 결정권은 수신자, 미성년 수신자에 더 민감한 τ).

**모델의 과업**: 입력 한국어 발화 하나를 받아 "수신자 보호가 필요한가"를 이진 판정. `주의`는 구 4-class의 `1(무례)·2(혐오)·3(긴급 행위위험)`의 **합집합**이다.

### 탐지 대상 taxonomy와 현재 소스·공백

| 위험 유형 | 구 라벨 | 현재 학습 소스 | 커버리지 | 공백 |
|---|---|---|---|---|
| 욕설·무례·개인공격 | 1 | UnSmile, KOLD, BEEP | 양호 | — |
| 보호집단 혐오·차별 | 2 | UnSmile, KOLD | 양호 | — |
| 그루밍·성적 유인 | 3a·3b | PAN12 predator 번역 190건 + 합성 하드케이스 | 취약 | 실그루밍 화법 소량, 시대·플랫폼 갭 |
| 금전 요구·사기 | (규칙 레이어) | **학습 데이터 없음** — 규칙 보조로만 보완(현재 OFF) | **없음** | 대화형 사회공학 사기 전무 |
| 구체적 협박 | 3c | GPT-4o/Gemini 합성 only | 취약 | 실데이터 없음 |
| 자해·자살 신호 | 3d | 합성 only | 취약 | 실데이터 없음, 임상 민감 |
| 강압적 통제·디지털 갈취 | 하드케이스 슬라이스 | `safe_hardcases_v{1..5}` 합성 only | 취약 | 공개 실데이터 희소 |

**핵심 진단**: 실데이터 커버리지가 있는 축은 혐오·욕설뿐이다. 그루밍은 소량(PAN12 190), **사기·협박·자해·강압통제는 사실상 합성/규칙에만 의존**한다. 이 공백이 [safe_이진_모델_개선_실험보고서.md](safe_이진_모델_개선_실험보고서.md) §8이 지적한 "완전 독립 실데이터 부재" 한계의 근원이다. 아래는 각 공백을 메울 외부 데이터셋 총망라(한국어 네이티브 + 외국어→한국어 번역)이다.

> **적합도 표기**: ★★★ 즉시 활용(한국어·라벨 정합) / ★★ 번역·가공 후 유효 / ★ 보조·참고.

## 2. 공백별 데이터셋 후보

### 2-A. 금전 사기 / 사회공학 (최대 공백)

현재 학습 데이터 0건, 서빙 규칙 레이어(정상 부정문 오탐으로 OFF 운영)로만 보완. 대화형 사회공학(계좌·송금·상품권·인증번호 요구)이 핵심.

| 데이터셋 | 언어/규모 | 접근·라이선스 | 번역 | 적합도 | 리스크·비고 |
|---|---|---|---|---|---|
| **보이스피싱 벤치마크** (HLT 2025) | 한국어 | FSS 보이스피싱 체험관 + AI-Hub, 논문 벤치마크 | 불필요 | ★★★ | 구어 통화체 → 메신저체 정규화 필요. 접근처 확인 요 |
| **Voice-Phishing-Detection-App/ML** | 한국어 | GitHub 공개 | 불필요 | ★★ | 커뮤니티 리소스, 규모·라벨 품질 검증 필요 |
| **PsyScam** | 영어, 사기리포트 1,126 / 사기범 직접 메시지 730 | arXiv 2505.15017, 공개 | 필요 | ★★ | 심리기법(긴급성·권위·미끼) 라벨 → 사회공학 화법에 정합 |
| **SMS Phishing/Smishing** | 영어 5,971 (Ham/Spam/Smishing) | 공개 | 필요 | ★ | 단문 스팸 — 대화형 사기와 결 다름, 보조 |
| **SMS Spam Collection** | 영어 5,572 | 공개(UCI) | 필요 | ★ | 스팸 일반, 보조 |

> DKTC의 **갈취(갈취 981)**도 금전 압박 성격이 있어 이 축에 부분 기여(아래 2-D 중복 소스).

### 2-B. 그루밍 / 성적 유인 (PAN12 190건 확장)

| 데이터셋 | 언어/규모 | 접근·라이선스 | 번역 | 적합도 | 리스크·비고 |
|---|---|---|---|---|---|
| **eSPD-datasets** | 영어 | GitLab `early-sexual-predator-detection`, 연구용 | 필요 | ★★ | PAN12 + PANC + VTPAN 전처리 제공. 기존 `translate_pan12.py` 재사용 |
| **ChatCoder2** | 영어 | 연구용(Perverted Justice) | 필요 | ★★ | PAN12 외 유일 공개 그루밍 소스. PANC = PAN12 non-grooming + ChatCoder2 grooming |

- **윤리**: 아동 대상 범죄 원데이터 → **재배포·git 커밋 금지, `data/` gitignore 하위 보관**(기존 PAN12 규약 동일). predator window만 `주의`로, 정상은 시드 clean에서.
- 기존 `extract_pan12.py`(window 추출) + `translate_pan12.py`(Gemini 현지화 번역·재개) 파이프라인을 ChatCoder2에 확장 적용 가능.

### 2-C. 자해 / 자살 신호 (3d — 합성 only)

| 데이터셋 | 언어/규모 | 접근·라이선스 | 번역 | 적합도 | 리스크·비고 |
|---|---|---|---|---|---|
| **Kaggle SuicideWatch/depression** | 영어 232,074 (116k/116k) | Kaggle 공개, Pushshift 수집 | 필요 | ★★ | 규모 큼. 게시글체 → 대화체 변환 필요 |
| **UMD Reddit Suicidality** | 영어 | **접근 신청 필요**(민감, IRB형) | 필요 | ★ | 임상 검수 라벨이나 절차 오래 걸림 |

- **주의**: 임상 민감 데이터. 번역 시 위험신호(자해 계획·암시) 순화 없이 보존되는지 검수 필수. 서비스상 자해 신호는 차단이 아니라 도움 연계가 맞을 수 있어 **후속 정책 확인 후** 투입.

### 2-D. 협박 / 디지털 갈취 (3c·갈취 — 합성 only) ★한국어 네이티브 최우선

| 데이터셋 | 언어/규모 | 접근·라이선스 | 번역 | 적합도 | 리스크·비고 |
|---|---|---|---|---|---|
| **DKTC** (`tunib-ai/DKTC`) | 한국어 train ~3,950 대화 | GitHub 공개, **CC-BY-NC-SA 4.0** | **불필요** | ★★★ | 협박 896 / 갈취 981 / 직장내괴롭힘 979 / 기타괴롭힘 1,094. test 5클래스×100(일반 포함) |

- **최우선 추천**: 한국어 네이티브·번역 불필요·라벨 정합. 4개 위협 클래스 대화 전체를 `주의`로 붕괴 매핑, test의 `일반(정상)`은 우리 시드 clean 유지(DKTC train엔 일반 없음 — 원 대회도 AI-Hub에서 조달 지시).
- **라이선스**: CC-BY-NC-SA 4.0 = 비상업·저작자표시·동일조건. 본 학술 private repo에는 적합하나 **상업화 시 재확인**(README의 상업 이용 주의와 동일 맥락). 원문 재배포 금지 조건 준수.
- 대화 단위 데이터라 우리 발화 단위 입력에 맞게 발화/윈도우 분해 필요.

### 2-E. 강압적 통제 / 관계 학대 (하드케이스 슬라이스 — 공개셋 희소)

| 데이터셋 | 언어/규모 | 접근·라이선스 | 번역 | 적합도 | 리스크·비고 |
|---|---|---|---|---|---|
| **Reddit 심리적 학대 6종** | 영어 1,500 posts | 논문 부속(2026) | 필요 | ★★ | 6개 심리학대 유형 라벨 → 강압통제 슬라이스에 정합 |
| **AAAI "Enhancing Detection of Relationship Abuse in Text"** | 영어 | 논문 리소스 | 필요 | ★ | 관계 학대 탐지 기법·데이터 참고 |
| **IPV 트위터셋** | 영어 6,348 / 8,767(#WhyIStayed) | 논문 리소스 | 필요 | ★ | 트윗체·서술체, 화법 갭 큼 |

- **알려진 한계**: "IPV/강압통제 전용 라벨셋 부재"가 학계 공통 지적. → **소량 번역 + 기존 하드케이스 합성(`build_safe_hardcase_dataset.py`) 병행**이 현실적. 감시·고립·비밀강요·복장통제 등은 이미 v4 하드케이스 슬라이스에 있음.

### 2-F. 한국어 혐오·윤리 보강 (기존 UnSmile/KOLD 확장 — 정상/주의 밸런스·다양성)

| 데이터셋 | 언어/규모 | 접근·라이선스 | 번역 | 적합도 | 리스크·비고 |
|---|---|---|---|---|---|
| **K-MHaS** | 한국어 109,692 (멀티라벨 혐오) | 공개, **CC BY-SA 4.0** | 불필요 | ★★★ | 대규모 멀티라벨 → `주의` 붕괴 용이 |
| **APEACH** | 한국어 3,844 | 공개, **CC BY-SA 4.0** | 불필요 | ★★★ | 크라우드 생성, 도메인 다양성 보강 |

## 3. 우선순위 제안

**① 즉시 활용 (한국어 네이티브·번역 불필요)**
1. **DKTC** — 협박·갈취·괴롭힘 공백을 네이티브로 즉시 메움. 최우선.
2. **K-MHaS / APEACH** — 혐오·욕설 축 다양성·규모 보강(CC BY-SA).
3. **보이스피싱 벤치마크 / Voice-Phishing GitHub** — 사기 축 첫 실데이터(접근처 확인 후).

**② 번역 트랙 (기존 PAN12 파이프라인 재사용)**
4. **ChatCoder2 / eSPD** — 그루밍 확장(`translate_pan12.py`·`extract_pan12.py` 재사용).
5. **PsyScam** — 사회공학 사기 화법(심리기법 라벨).
6. **Kaggle SuicideWatch** — 자해 신호(정책 확인 후, 게시글→대화체 변환).

**③ 보류·병행**
7. **강압통제 IPV셋** — 공개셋 희소 → 소량 번역 + 하드케이스 합성 병행.
8. **AI-Hub 텍스트 윤리검증** — 승인 절차 확인 후.
9. **SMS 스팸류** — 대화형과 결이 달라 보조.

## 4. 리스크·윤리·방법론 준수

기존 규약([safe_이진_재학습_평가_파이프라인.md](safe_이진_재학습_평가_파이프라인.md), [grooming_번역_증강_계획.md](grooming_번역_증강_계획.md))을 그대로 승계한다.

- **홀드아웃 분리**: 모든 외부/번역분은 **train 전용**. 실데이터 홀드아웃(AI-Hub/BEEP)·소비된 blind와 완전 분리, `src/data/dedup.py` MinHash(0.8)로 교차·소스 간 dedup 후 학습.
- **번역투 편향 가드**: `정상`=한국어 원어 / `주의`=번역체 지름길 학습 방지 — 정상 대화도 동일 파이프라인으로 소량 번역해 양쪽 투입, 문체 대조 미니셋으로 "문체 아닌 내용으로 구분"하는지 상시 모니터링.
- **라이선스**: DKTC(CC-BY-NC-SA, 비상업)·K-MHaS/APEACH(CC BY-SA, 동일조건)·AI-Hub(승인·약관)·그루밍 원데이터(재배포·커밋 금지) 각각 준수. 상업화 전환 시 NC/SA 조건 전면 재검토.
- **민감성**: 그루밍(아동 범죄)·자해 원데이터는 저장소 밖 보관, 보고서엔 통계만. 자해는 서비스 대응 정책(차단 vs 도움 연계) 확정 후 라벨링 방향 결정.
- **재사용 자산**: `scripts/translate_pan12.py`(Gemini 배치 번역·현지화·재개), `scripts/extract_pan12.py`(대화 window 추출), `src/data/dedup.py`(MinHash), `scripts/build_safe_hardcase_dataset.py`(합성 하드케이스). 신규 소스는 이들에 어댑터만 추가하면 파이프라인 재사용 가능.
